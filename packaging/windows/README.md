# Windows 打包

## 规划

- 前端：WinUI 3（unpackaged 或 MSIX），x64 / ARM64；
- 后端：`sqarvo-backend.exe` 随应用一起安装，由前端作为子进程启动；
- 安装器：MSIX；若需要后台常驻则应改用系统服务方案（尚未设计）。
