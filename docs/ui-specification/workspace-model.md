# 工作区模型与区域规范

本文件定义 v0.2.3 起的目标界面结构：区域划分、对象与信息面板的对应关系、标签与会话模型、
跨平台映射，以及**不照抄原型**的部分。

> **行为口径以 [ui-behavior-contract.md](ui-behavior-contract.md) 为准**：动作、可用性条件、
> 结果文案、快捷键与状态转换都在那份契约里（以 Linux 客户端代码为依据）；本文件只负责
> 版式、区域与尺寸，两者冲突时行为按契约、版式按本文件。

- 结构来源：Figma `v0.2 / Low-Fi / 1200×800`（node `12:1493`，1200×800）；同族帧
  `v0.2`（`7:171`）、`v0.2-backup`（`12:732`）、`oranginal`（`7:452`）不是本规范的依据。
- 配套决策：[ADR 0021](../decisions/0021-workspace-tab-session.md)（标签 ↔ 会话）、
  [ADR 0022](../decisions/0022-table-browse-pagination.md)（分页/排序/筛选/总数）、
  [ADR 0023](../decisions/0023-cross-platform-shell.md)（区域一致与原生控件）。
- 设计原则与六种状态的要求见 [design-principles.md](design-principles.md)；本文件只定义结构，
  不重复原则。

> 原型是低保真结构模型：`LO-FI` 徽章、`CN`/`NQ`/`TB`/`VW`/`ƒx`/`QR` 代号、右下角
> `appendinfo` 注释组都是图例，不是产品元素。附录 A 列出全部有意偏差。

## 1. 基准

| 项 | 值 |
|---|---|
| 参考窗口 | 1200 × 800 |
| 默认窗口（Linux） | 1200 × 800（原 1100 × 720） |
| 最小窗口 | 960 × 640（低于此值只保证可用，不保证不横向滚动） |

| 信息面板宽度 | 280（可拖拽 240–520；v0.2.3.2 起常驻，不可折叠） |

| 字号 | 标题 13 semibold；界面 12；表头 12；状态栏 11 |

## 2. 区域

六个区域自外向内、自上而下：

| 区域 | 高度 | 内容 | GTK 载体 |
|---|---|---|---|
| 01 窗口外壳 | 64 | 标题栏 40（居中标题 + 右侧控件）+ 菜单行 24 | `AdwHeaderBar`（Linux 无菜单行，见 §8） |
| 02 主工具条 | 44 | 左组：连接 / 新建查询；分隔线；**种类入口**（`Tables` / `Views` / `Functions` / `Queries`，纯文字无图标，与「新建查询」同一套 flat 样式、离分隔线同样 14px）；高亮 = 当前列的种类 | `GtkBox` + flat 按钮 |

注：主工具条的种类入口是纯拉丁文字（`Tables` / `Views` / `Functions` / `Queries`），和中文
「新建查询」同一行混排时，字面会比中文高 2px（Pango 的中文 em 盒更靠下）。按实测用
`.sqarvo-kind label { margin-top: 2px }` 把字下移，**按钮盒子与命中区不变**（仍同高同 y），
这条补偿有单测锁着。

| 03 对象树 | 636（自适应） | `My Connections` 头 + 多连接树 + 种类分组 | `GtkPaned` 左栏，`GtkTreeListModel` |
| 04 工作区 | 636 | 标签条 47（`AdwTabBar` 实测）+ 表格工具条 32×2（行变更/事务动作行 / 状态行）+ 表格 + 信息面板 | `AdwTabView` + `GtkStack` + `GtkColumnView` |
| 05 状态栏 | 56 | 分栏线延伸到底，左侧整块属对象树功能区（留空）；右侧两行：行操作/分页器；SQL 摘要（紧贴行操作正下方）/记录计数/最后刷新 | `GtkBox`：左边沟 + 1px 竖线 + 右列两行 |
| （06 信息面板） | 与表格同高 | 连接 / 库 / 表三种内容 | `GtkBox` + `GtkStack` + `GtkRevealer` |

原型里 05 叫 `06 Status Bar`、信息面板没有独立区域名（占的是注释位）。本规范统一称
**05 状态栏** 与 **信息面板（Inspector）**，避免沿用图例编号。

### 2.1 布局算术

```text
contentHeight = windowHeight - 108 - 56      # 108 = 外壳 64 + 工具条 44（v0.2.3.3：76 → 44）
contentWidth  = windowWidth  - sidebarWidth
tabStrip      顶高 47                        # AdwTabBar 实测；原型画的是 24
tableActions  顶高 32 × 2 = 64               # 第 1 行事务控制，第 2 行行变更与次要动作
gridHeight   = contentHeight - 47 - 64
gridWidth    = contentWidth - 18（左内边距）- 3（右内边距）- [10（间隙）+ inspectorWidth]
```

1200 × 800：`contentHeight = 636`、`gridHeight = 525`（`= 636 − 47 − 64`）。表格工具条在 960 宽下
单行放不下全部控件（会截断、重叠），拆两行是**有意取舍**，见附录 A 第 8 条；标签条高度取
`AdwTabBar` 实测值而非原型的 24，见附录 A 第 10 条。

1200 × 800 下的实际宽度：

| inspector | gridWidth | 说明 |
|---|---:|---|
| 240 | 692 | 下限 |
| 280 | 652 | 默认 |
| 320 | 612 | 上限附近 |

信息面板在 v0.2.3.2 起**常驻**，因此没有「折叠 = 942」这一档：表格永远少 280（默认）左右。

原型里的 772 是**为注释图例让位算出来的**，不是需求。7 列自然宽度合计就是 772
（32 + 60 + 80 + 160 + 72 + 152 + 112 + 104），所以在默认 280 面板下表格必然横向滚动或
列宽压缩——这是接受的取舍，验收时必须检查横向滚动条的可用性，不得让列被静默裁掉。

## 3. 标签模型

- 工作区有一个**固定的 `Objects` 页**：**钉住（pinned）在标签条最左**、宽 84、只显示
  图标、没有关闭按钮（`AdwTabPage:pinned`，libadwaita 1.2+ 确有该 API）。它不因打开 /
  关闭其它标签而改变大小与位置，也不占标签上限名额。
- `Objects` 页的内容是**对象列表**，与对象树选中联动（v0.2.3.2 起；旧版「当前选中对象
  概览」已废弃）：
  - 选中某个库（catalog / schema）→ 列出该库的**表**；
  - 选中 `Tables` 分组或它的下一级 → 该库的表；
  - 选中 `Views` 分组或它的下一级 → 该库的视图；
  - 选中连接、占位行 → 空态文案（「没有选中对象」+ 操作说明），不是空白。
- 列表由页面自己发 `ListNodes(parent=catalog, filter.kinds=[…])`（自带分页 token 与
  「加载更多」），**不读树的分组层状态**：树没展开过也要能看到完整列表。
  行双击打开表数据标签（与树的双击同一条路径）。
- **列表的形态是单列表格**（v0.2.3.3，`GtkListView` + 单选模型，不是 `GtkListBox`）：
  - 页内**只有标题「Objects」+ 列表**：标题与列表之间不再有「sqarvo_demo · 表」这类
    作用域说明行（v0.2.3.3 删除），作用域只由列表内容表达；
  - 每行 = `[种类图标] [名称] [种类]`；图标走与对象树**同一个** `kind_icon` 映射
    （表 `view-grid-symbolic`、视图 `view-reveal-symbolic`），不另写一套；
  - 行高 32、名称 13px/500、行分隔线 1px / 10%、悬停 4%、选中 accent 25%——四样都
    与数据网格同一口径（改网格时一起改，`theme.rs` 的单测锁住）；
  - 单击**只选中**，并同步右侧信息面板（列表是第三个「选中」入口）；双击 / 回车才
    打开表数据标签。**不反向改树的选中**——树选中会驱动本页换作用域，回写会形成回环；
  - 作用域没变（同一个库、同一类）时**不重发 `ListNodes`**，行保留、列表不闪；树里换了
    选中就把行高亮清掉（高亮属于上一次浏览，不清会和右侧面板错位）；
  - **重新进入本页（从别的标签切回来）不选中任何行**：上一次的高亮属于上一次浏览，
    切回来时清空；列表内容与信息面板都不动。
- **主工具条的种类入口**（v0.2.3.3，四个入口**双向联动**）：`Tables` / `Views` / `Functions` /
  `Queries` 点一下 = 在对象树里选中该库下的**对应分组行**（库未展开时先展开）+ 切到本页。
  `Tables` / `Views` 列出对象；`Functions` / `Queries` 没有可拉取的列表，页面如实说明
  「尚未实现」，不摆假数据——但**树里照样选中分组行**，否则就只有一半联动。
  与手动点树是同一段代码；**一次选中到位**——先选库再选分组会看到高亮先落到库上再跳到分组
  （两段选中 + 两次滚动）；目标库是**树里当前选中项所在的库**（选中的表 / 视图 / 分组也算），
  只有什么都没选中时才用活动连接的默认库——不能锁死在默认库上。
  工具条高亮始终等于本页正在列的种类（表数据标签打开时等于该表的种类）；反方向也联动——
  在树里选中任意分组行（`Tables` / `Views` / `Functions` / `Queries`）或某个表 / 视图时，
  `Objects` 页跟着换作用域，工具条高亮同一次刷新跟上（只在 `Objects` 页是当前标签时推，
  停在表标签上时高亮的含义是那个标签的表）。
- 页面与信息面板**互相独立**：面板回答「这个对象是什么」，`Objects` 页回答「这个库里
  有什么」。不再共享同一份快照，也不再有「在信息面板查看 DDL」快捷按钮；两者唯一的
  耦合是「选中事件」——点列表行与点树节点同样驱动面板（v0.2.3.3）。
- 标签有两种：**表数据标签**（`对象 @ 库`）与**查询标签**（`查询 N`）。表数据标签显示
  2px 顶部强调线 + 关闭按钮；查询标签同构。
- 标签名格式：`<对象名> @ <catalog>`；连接名只在标题栏出现（§5 标题规则），不重复进标签。
- `＋` 新建查询标签；表标签只能由树/搜索结果打开。
- 关闭标签：有脏行 → 保存 / 放弃 / 取消 三选；有未提交事务 → 明确提示「回滚该标签的事务」。
- 标签与数据库会话一一对应（ADR 0021）：标签创建时开会话，关闭时关会话。
- 标签上限默认 8，与 `QueryRegistry.max_concurrent` 对齐；超限时禁止新建并给出可读原因，
  不是静默失败。
- **同一张表重复打开时复用已有标签**（v0.2.3.3）：对象名 + catalog + 连接三者完全一致即
  视为同一张表，只切换到已有标签，不新建标签、不新建会话、不重载数据。这是**有意语义**
  ——不要第二个会话来打开同一张表（否则同一张表会有两份脏行与两条互不可见的事务）。
  复用也**不受**上面的标签上限约束：已开满 8 个标签时仍可切到已存在的表标签。
- 切换标签**不重建**会话，也不改变对象树的展开状态。

## 4. 对象树

- 根是 `My Connections`，其下是**连接**（来自 `connections.json`），再下是 catalog
  （SQLite `main`/`temp`/`ATTACH`，MariaDB 为可见库），再下按种类分组。
- 连接条目按**身份键**唯一（#145）：服务器型 = 驱动 + 主机（大小写不敏感）+ 端口 +
  用户名 + 库（空库名也参与比较）；文件型 = 驱动 + 规范化绝对路径（`./a.db`、
  `a.db` 与大小写差异视为同一文件）。再次「保存并连接」同一目标时**更新原条目**的
  非身份字段（名称 / TLS 等；改库名、用户名或端口是另一个目标，各自独立），不追加；
  凭据引用复用，密码变化覆盖原引用指向的密钥，
  不在系统凭据库里堆新条目。加载配置时已有的重复条目按同一规则合并并记一行日志
  （保留最近一次保存的那条，不静默丢数据）。
- 种类分组的顺序固定：`Tables` → `Views` → `Functions` → `Queries`。
- 分组是**客户端虚拟层**，不是服务端层级：契约中的层序只有
  Catalog → Table/View/Sequence → Column/Index/Trigger（见 `proto/services/v1/metadata.proto`
  的层级表）。分组通过 `ListNodesRequest.filter.kinds` 拉取，每个分组有自己的分页 token。
  **展开 catalog 本身 0 次 RPC**（只建四个分组行）；只有展开某个分组才发那一次的
  `filter.kinds`。v0.2.3.3 起分组**不随 catalog 自动展开**：双击库之后用户的注意力在
  `Objects` 页（那里已经列出表），树里的 `Tables` / `Views` 保持收起，由用户点开。
- `Functions` / `Queries`（v0.2.3.3）**只有入口、没有列表能力**：契约里还没有这两个种类的
  `ListNodes` 拉取，也没有「已保存的查询」这一层。分组行照常显示（带自己的图标，名字是
  英文，与 `Tables` / `Views` 同一套写法），展开时写一行「尚未实现（点开看说明，不发请求）」，
  **0 次 RPC、不摆假数据**；在 `Objects` 页选中它们时页面如实说明原因。PostgreSQL 的
  `TYPE` 分组同理留待以后。
- 选中态：整行底色 + 3px 左侧色条；键盘上下移动必须与鼠标同效。
- **单击 / 双击语义（v0.2.3.2，全树统一）**：单击**只选中**（信息面板与 `Objects` 页跟着
  选中换内容，不展开、不打开、不连接）；双击（或回车）= 激活：
  表 / 视图 → 打开数据标签；连接 → 按保存的凭据连接（已连接则展开 / 收起）；
  库 / 分组 → 展开 / 收起（展开库只出现分组行，分组仍是收起的，见上一条）。
  行首箭头按钮永远可以单击展开 / 收起。
  「加载更多…」是分页动作，单击（选中）即继续拉下一页——它不需要双击。
- 展开一张**表**先出现四个二级分组行：`Fields` → `Indexes` → `Foreign Keys` →
  `Triggers`，展开某一组才发那一次的 `ListNodes(filter.kinds=…)`（各自分页 token）。
  `Fields` 就是原来的列层。视图仍直接列出列（没有另外四组）。
- `Foreign Keys` 目前**没有任何驱动实现**（proto 没有外键种类）：该组展开时显示一行
  「驱动未提供外键列表（capability.unsupported）」，不发 RPC，也不摆假数据。
- 行内不显示工具按钮；右键菜单对表 / 视图**只保留「打开」**（「查看 DDL」在 v0.2.3.2
  移除；DDL 改由信息面板内的 `[DDL]` 页查看）。连接节点的右键是连接 / 断开连接 /
  刷新连接 / 编辑连接… / 删除连接；分组节点是刷新这一组；库 / schema 节点是刷新库。
- **刷新入口只在右键菜单**（侧栏底部没有刷新按钮，也没有分割线：侧栏就是对象树本体）。
  `刷新连接` 重读该连接已经建立的层（目录层与已展开的层，就地重发第一页，不收起子树）；
  连接节点收起、一层都还没建立时不做请求，展开时按正常路径读取。`刷新库` 重读该库 /
  schema 已展开的 `Tables` / `Views` 等分组与直接子对象层；分组都收起时只清掉缓存，
  展开时自然重拉。菜单栏的「刷新」（`F5`）仍是整棵树（全部连接）的入口。
- 侧栏**没有平铺列表，也没有页脚按钮**：对象树是唯一入口。侧栏底部不再显示
  「本页 N 条，累计 N 条」这类分页统计（分页状态在「加载更多…」行与日志里）。
- **点击连接 = 按保存的凭据连接**（#144）：启动态侧栏与连上后的对象树是**同一个组件**
  （`tree::TreePanel`）、同一个入口（`connect_saved`）。未连接时点一下就用
  `connections.json` 里的
  `credential_ref` 建立浏览会话（不读密码、不新增凭据），成功后落到工作区并在树里
  展开该连接一层；已连接时点一下是展开 / 收起节点；连接中 / 断开中重复点击被忽略。
  配置里没有凭据引用（或密钥库里已取不到密码）时给出明确提示并打开预填的连接对话框，
  让用户补密码——不静默失败。
- 启动态侧栏的右键菜单（与连接态同一份实现）：`编辑连接…`（打开预填对话框）、
  `断开连接`（仅已连接时出现）、`刷新连接`（仅已连接时出现）、`删除连接`（二次确认后从
  `connections.json`
  移除；尽力删除该 `credential_ref` 的密钥条目，删不掉时如实提示「配置已删除，密钥条目
  未删除（错误码）」）。不常用的动作不占左键。
- 搜索框保持在**树顶部**（`GtkSearchEntry`，防抖 250ms），不采纳原型的「搜索框在窗口底部」。

## 5. 信息面板（Inspector）

右侧面板，宽度 280 起，**常驻显示**（v0.2.3.2 起没有折叠按钮、没有 `Ctrl+I`；宽度仍可
拖、**窗口级记忆**——启动态、连接态、切换连接都读同一个值，拖一次全局生效；旧版按
连接记录的宽度在首次读取时取最常用的值迁移。存独立的窗口状态文件，不写进
`connections.json`）。内容由**当前选中
的对象种类**决定，并且只由「选中」事件驱动——鼠标经过不改变面板内容：

| 选中 | 面板内容 | 数据来源 |
|---|---|---|
| 连接 | 驱动、地址（`host:port` 或文件路径）、默认库、用户、TLS 模式、凭据引用（不含密码）、服务端版本、连接延迟、会话数 | `connections.json` + `ConnectOutcome` + `ListSessions` |
| 库 / catalog | 名称、表与视图计数（以已展开结果为准，不主动全量统计） | `ListNodes` |
| 表 / 视图 | 顶部切换 **[DDL] / [表信息]**；DDL = `GetDdl` 正文（与表信息同字号、不折行、横向滚动；`exact=false` 时正文上方一行拼装警示）；表信息 = 列（类型/可空/默认值/字符集/排序规则）、主键、索引与触发器列表、已加载行数 | `GetDdl` / `GetColumns` / `GetPrimaryKey` / `ListNodes` |
| 列 | 该列的完整属性（类型、可空、默认值四态、字符集与排序规则） | `GetColumns` |
| 索引 / 触发器 | 仅 DDL；MariaDB 的索引与触发器无独立 DDL → 显示明确「不支持」文案与错误码 | `GetDdl` + `metadata.object_kind_unsupported` |

规则：

- 拿不到的字段**不出现**，不用 `—`、`N/A` 或空占位冒充。
- **启动态（还没连上任何数据库）面板同样常驻 280**；空态与选中态共用同一套外壳
  （标题「信息面板」+ 分隔线），内容区**留白**，不写「没有选中对象」这类说明文字。
  与连接态是同一份实现，不存在「启动态无面板 / 折叠」这一档。
- 表/视图的 `[DDL] / [表信息]` 是面板内切换，不改变标签与选中；选择在标签生命周期内记忆。
- 这一对切换是**两个独立 toggle**，不是 `.linked` 分段容器：选中态是贴着文字的小圆角块
  （四角都圆、横向内边距 4、命中区仍不小于 24），与上方横线留 6px。面板内容列统一贴
  内容区左端——标题块、切换条、「表信息」行与 DDL 正文共用一条左基准线，也就是分隔线的
  左顶点（选中块左边缘贴线，块内标签因按钮内边距缩进 4px）。拉丁标签另做 1px 垂直光学
  补偿：「DDL」与「表信息」的行盒居中会让前者看着偏高。
- DDL 页只有正文：**不显示**来源徽标、来源说明行与「复制」按钮（它们夹在切换与正文之间
  只是噪音）；`exact = false`（客户端拼装）时正文上方仍必须有琥珀警示。复制走选中 +
  `Ctrl+C`。正文不折行、横向滚动且滚动条常驻。
- **面板正文只有一个口径**：DDL 正文与「表信息」内容同字体、同字号、同字重——
  `.sqarvo-panel-text` = 10px / 400（`layout::FONT_PANEL`）。面板是次要信息，视觉重心
  在数据网格，所以正文比网格小得多、也不加粗；层级只靠颜色（字段标签 dim）与分节间距，
  不用 Medium / Semibold。12px 会裁 CJK 笔画的问题只约束**网格单元格**，与面板无关。
- 权限不足、对象不存在、不支持种类都要显示可读文案 + 稳定错误码。
- DDL 面板从底部 `GtkRevealer`（现实现）迁入本面板；列信息从页内 Overlay 浮层迁入
  「表信息」页，浮层与其截图绕行代码一并删除。
- 连接信息里的端点文件路径（现 UI 底部那行 `端点文件：…`）迁入本面板与
  「帮助 → 关于 Squarvo」（#139 起诊断信息集中在该对话框），不在主界面常驻。

### 5.1 标题规则

窗口标题 = `<当前标签对象> @ <catalog> (<连接名>)`；无标签时 = `<连接名> - <连接类型>`；
未连接时 = `Sqarvo`。副标题位显示「已连接 · 驱动（driver_id）· 服务端版本」。
标题属于**当前标签**，不是窗口：切换标签即切换标题。

## 6. 表格浏览

- 结构：行号列（32，行号来自 offset，不是主键）+ 表头两行（列名 / 原始类型）+ 数据行。
- 列宽：行号列固定 32 不可拖；数据列可拖拽列边界，第二行的类型条带跟随列宽（拖宽 /
  拖窄都对齐），双击列边界按内容自适应（GTK 4.10+ 原生行为）。类型条带不参与外层最小
  宽度计算——宽表只横向滚动，不挤压右侧信息面板。
- 横向滚动条：数据网格与查询结果关闭 GTK overlay 自动淡出，内容超宽时常驻显示。
  否则「滚动到最右 → 最大化窗口」后滚动条可能淡出，而可滚范围只剩几十像素，用户
  无法回到第一列。滚动条本身必须始终可见、可点击。
- 窗口最大化后，所有表 / 结果网格的横向滚动位置回到第一列。只重置滚动位置，不重新
  浏览或执行查询，未提交的编辑与已加载结果保持不变。
- 排序与筛选：表头点击排序、漏斗图标打开筛选与排序面板、眼睛图标控制列显隐；三者都只作用于
  当前标签，不写回数据库。图标语义与尺寸见 [design-principles.md](design-principles.md) §图标。
- 筛选与排序面板（`FS`）：挂在漏斗按钮上的 **popover**（`autohide = false`，内容宽 430）——
  位置由 GTK 贴着按钮算（Wayland 下应用无权给独立窗口定位，独立窗口只会被合成器居中），
  而且是独立 popup surface，不在主窗口 render tree 里重排，**没有拖影**。锚点固定落在
  面板上沿的**黄金分割点**（0.618，偏右）。点「应用」后**不关闭**，点按钮 / ✕ / Esc 才关。
  - 面板里的改动是**草稿**：点「应用」才同时生效（筛选 + 排序一起提交，并回到第 1 页）；
    关闭面板丢弃草稿。标题条右侧显示「已应用 / 有未应用的更改」。
  - **面板里只有一种字号（12px）**，与对象树一致：正文、按钮、下拉、输入框、说明字统一，
    层级只靠字重与颜色；列表行 24px（不是 `boxed-list` 的 44px）。
  - 筛选条件：列 + 算子 + 值，多条按 AND 组合；算子**只写符号**（`=` / `≠` / `≤` / `LIKE` /
    `IS NULL`）且**不显示下拉箭头**（旁边就是值，箭头是噪音），列下拉固定宽度（不随面板
    拉伸）；点条件行**就地展开**为三件套编辑器（回车或 `✓` 提交，`✗` 或点面板空白处收起）。
    编辑态与只读态**同一套外观**：同底色（不加强调色）、同行高、同字号，只把文字换成控件；
    行尾始终只有一个 `✗`（关闭面板的 `✗` 与它同一套线条图标）。
  - 排序：列 + 方向（`asc` / `desc`，不写中文、不加方向图标、方向下拉不显示箭头），支持多列；
    列表行是 `列名  asc|desc`（**不写序号**：从上到下就是优先级），行尾是三个线条图标
    `^` `v` `✗`（调优先级 / 删除，与面板其它 `✗` 同一风格），点行切换方向；
    与表头点击排序共用同一份排序状态（表头 ▲▼ 标记同步）。
  - 已加的条件 / 排序键是淡底色 + 圆角的「实体条」（悬停再亮一档）：点开行内编辑器时
    形态变化自然，不会出现「一行文字突然变成一堆控件」。
  - 底部只有一个调整区：分隔线 + 右对齐的「清空」「应用」两个按钮。文案不带作用域
    （面板里只有筛选与排序），不写说明段落——规则靠控件本身表达（见
    [design-principles.md](design-principles.md) §自解释优先）。
- 选择：多选（Ctrl/Shift），状态栏右侧显示 `N selected`；多行删除走批量语义与风险确认
  （ADR 0017 的 `ApplyRowChanges.deletes`）。
- 分页：offset 分页 + 总数三态（精确 / 估计 / 未知），见 ADR 0022。页码只读显示，只提供
  首页 / 上页 / 下页 / 末页；跳转到远处页码在 v0.2.3 不提供。
- 末尾信息（状态栏行 2）：`SELECT … LIMIT 0,1000` 形式的摘要（由当前筛选与排序拼出，
  只读）与 `Last Refresh: <1m>`；本版不再显示行号区间（v0.2.3.3，见 §7）。
- **信息不重复**：页码与总数只在状态栏行 1 的分页器旁出现一次；表格工具条下方那一行只放
  本次操作的临时消息（错误 / 进度 / 结果），不再写「本页 N 行 · 共 N 行 · 第 X 页」。
- 表格工具条**没有**「重新读取」图标：刷新入口只有状态栏行 1 行操作组里的 `⟳`
  （v0.2.3.3 删掉了 `Last Refresh` 旁边那个重复按钮）。有未提交的更改时刷新被拒绝
  （与翻页/排序/筛选同一条守卫），tooltip 说明原因。
- 滚动到底**不再**自动取下一页（与 offset 分页互斥）；改由分页器驱动，翻页后回到顶部。
- 只读态、无主键表、视图、只读事务都要在表格上方有常驻徽标，不能只靠禁用控件。

### 6.1 导出 CSV（`EX` / `Ctrl+Shift+E`，#120）

- 范围：查询结果标签导出**已加载的行**（不重新执行 SQL）；表数据标签在确认对话框里选
  **当前页**（只写本页已加载行）或**整张表**（按 offset 逐页取回，带进度与取消）。
  被客户端结果集上限截断、仍在分批加载或查询被取消时，确认对话框与完成提示都写明
  「不是全部结果」；CSV 文件本身只有表头与数据行，不含「全部」声明。
  整表导出在取消或任意失败时不留半截文件（`CsvSink` 的临时文件 + rename 语义不变）。
- 列：表数据页导出**全部列**；`CC` 列显隐只影响渲染，不改变导出口径（与工具提示一致）。
- 值：空字段 = SQL NULL；空字符串写为 `""`；二进制写占位 `(BLOB n bytes)`，不写原始
  字节；Decimal 保留原文；日期 / 时间 / 时间戳用 ISO 8601（日期与时间之间是 `T`）。
- **公式注入防护（默认开启，#137）**：**文本类**值（Text / JSON / UUID / Unsupported）
  如果以 `=`、`+`、`-`、`@`、制表符（`\t`）或回车（`\r`）开头，写出时前置单引号（`'`），
  并按 RFC 4180 规则加引号（例如 `=1+1` 写成 `'=1+1`，`=1,2` 写成 `"'=1,2"`）。
  非文本类值（整数、浮点、Decimal、布尔、日期时间）**不加**：`-5` 写成 `'-5` 会改变
  数值语义。确认对话框里的「公式注入防护」开关可以关闭（QA 用
  `--qa-export-raw-values`），关闭后写原始值，完成提示如实说明开关状态。
- 首列以 `#` 开头的值会被引号包裹：这样「以 `#` 开头的行是注释」不会误伤数据行。
- 截断标记：被服务端截断的单元格在确认对话框里统计并警告，文件按已返回的前缀写出；
  只要本文件含截断单元格，就在**所有数据行之后**追加一行注释（行尾与数据行一致）：

  ```text
  # sqarvo: 本文件含 N 个被截断的单元格（仅前缀，不是完整值）：<列名列表>
  ```

  `<列名列表>` 用 `, ` 分隔；**没有截断时不写这一行**。读文件的程序应忽略以 `#`
  开头的行——该行是文件里唯一的注释行，且只在文件末尾出现。
- 文件：目标路径拒绝相对路径与 `..` 段，父目录必须存在；默认不覆盖，已存在时需二次
  确认；写临时文件（0600）→ 成功后改名，取消 / 失败不留半截文件与临时文件。

## 7. 状态栏

两行，**被侧栏分栏线分成左右两块**（v0.2.3.3）：分栏线一直延伸到底部，线左侧整块属于
对象树功能区，右侧是工作区的两行读数。

```text
       ← 对象树功能区 →│← 工作区
行1：                 [行操作图标：新增 删除 应用 撤销 刷新 取消]   [分页器]
行2：                 [SQL 摘要]                                            [Last Refresh]
```

- 左边沟**不放任何控件**（v0.2.3.3 删除了「连接过滤」）：搜索在树顶部，状态栏这一格
  是纯空白，宽度跟随侧栏分栏位置（拖分栏线时同步），保证分割线与分栏线在同一根轴上。
- **SQL 摘要紧贴行操作正下方**（同一左边界）：行 2 的左段就是 SQL，不再跨到窗口最左。
- 行 2 **只有两段**：SQL 摘要（左，可省略）与 `Last Refresh`（右）。记录位置（第 N–M 行）、
  连接名、库名、事务状态、上次耗时都不再出现在状态栏（v0.2.3.3）——页码/总数在行 1 的
  分页器里，表名/库/事务在表格工具条里，同一屏重复三遍只会挤。没开表（空态 / 查询标签 /
  Objects 页）时，`Last Refresh` 那一格换成一行启动摘要（「未连接 · 驱动 N · 浏览会话 M」
  或连接名）。
- 行 2 的文案用 **ASCII 冒号**（`SQL:` / `Last Refresh:`）：全角「：」会把中文行盒高度带进
  来，和纯拉丁的 `Last Refresh:` 不在同一条基线上（实测偏高 2px）。
- 右下角**没有第二个刷新按钮**（v0.2.3.3 删除）：行操作里的 `⟳` 就是刷新当前表，
  同一屏两个刷新入口只会让人猜差异。
- 「对象树 / 平铺列表」切换在 v0.2.3.2 **不存在**（平铺列表已删除，附录 A 第 9 条）。
- 行操作六个按钮是**图标 + tooltip**（同一段文字登记为可访问名）：新增 / 删除 / 应用 /
  撤销 / 刷新 / 取消，尺寸按 [design-principles.md](design-principles.md) §图标 的**唯一**
  标准：基准盒 16 × 16（以 `+` 为准），四个墨迹比例偏离的字形按实测补偿（`✓` 14、`⟳` 14、
  `↶` 18、`■` 18）。缩放下限 13px——再小描边不足 1.3px，渲染会「发虚」。
  「取消」只在提交批次在途时可点，语义见 ADR 0018（中止本批并整批回滚，不是撤销已提交的
  数据）；「撤销」只丢弃本地未提交的编辑。
- 行操作按钮的可用性由当前标签状态决定；无标签时全部禁用并说明原因。
- ~~行 2 中段是行号区间~~（v0.2.3.3 删除）：页码与总数在行 1 分页器旁，行号区间不再重复。
- 事务状态只在**表格工具条**出现（v0.2.3.3 起状态栏不再写）：它是会话级信息，标签名
  `对象 @ 库` 与表格工具条的表名行已经把「哪个表 / 哪个库 / 在不在事务里」说全了。

## 11. 密度与可访问性

- 紧凑密度通过全局 CSS 实现（行高 24/32、字号 12/13）；只在 Linux 启用，Windows/macOS
  保留系统默认密度，只对齐信息层级。
- 紧凑化不得破坏：焦点可达（键盘可走完树 → 标签 → 表格 → 面板）、可见的焦点环、
  最小点击区域 24×24、对比度 ≥ 4.5:1（正文）。
- 表格与树必须能用键盘完成选择与滚动。信息面板在 v0.2.3.2 起常驻，不存在「折叠后焦点
  留在不可见控件上」这一情形。
