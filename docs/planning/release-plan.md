# 发布计划

- 本文件定义版本范围与退出标准；阶段与依赖见 [development-plan.md](development-plan.md)。
- 版本号遵循语义化版本：`0.x` 期间 API 与数据格式可能变化，`1.0` 起承诺兼容策略。
- **不承诺发布日期**；版本以能力与质量门槛为准。

## 版本概览

| 版本 | 主题 | 包含能力 | 不包含 |
|---|---|---|---|
| v0.1 | 基础架构与数据库连接（后端） | 本地 IPC + token、gRPC 契约、Driver SPI、SQLite 连接/执行/分批/取消 | 前端可用界面、PostgreSQL、元数据浏览、事务 UI |
| v0.2 | SQL 编辑器与查询结果 | 至少一端前端接入；凭据存储；PostgreSQL；SQL 编辑器、执行、取消、结果虚拟化 | 数据编辑、对象管理、导入导出 |
| v0.3 | 数据浏览与编辑 | 表数据浏览、安全编辑、事务控制与状态展示 | 对象管理、结构对比、ER 图 |
| v0.4 | 数据库对象管理 | 对象树、列信息、DDL 查看、对象搜索 | 导入导出、结构同步 |
| v0.5 | 导入导出与结构管理 | CSV/JSON/SQL 导入导出、结构对比与迁移脚本 | ER 图、数据同步 |
| v1.0 | 首个完整可用版本 | 三平台一致、多驱动（SQLite/PostgreSQL/MySQL）、性能与安全验收、打包 | 远程后端、团队协作 |

> 版本内容会随需求评审调整；调整必须同步 `roadmap.md`、`milestones.md` 与本文件。

## 各版本退出标准

### v0.1

- M0、M1、M2 完成；
- 后端可通过真实 gRPC 客户端连接 SQLite 并完成执行、分批、取消、关闭；
- 所有检查（fmt/clippy/test/doc）通过；
- 明确声明「无前端、无网络数据库支持」。

### v0.2

- 至少一个平台前端可启动后端、完成 token 握手并执行 SQL；
- PostgreSQL 驱动通过 testkit；
- 凭据存储可用且缺失时明确报错；
- 结果集虚拟化与分批拉取在 10 万行场景可用（有基准记录）。

### v0.3

- 表数据浏览与编辑可提交/回滚，脏数据可见；
- 事务状态在 UI 中可见，断连时事务被清理；
- 编辑操作的风险提示与只读模式可验证。

### v0.4

- 对象树懒加载可分页展开；
- 列信息保留原始类型与可空性；
- DDL 查看标注是否为原文。

### v0.5

- 导入导出流式处理，路径校验与覆盖保护；
- 结构对比只生成脚本、不自动执行；
- 大文件场景有内存上限与错误处理。

### v1.0

- 三平台构建、安装与基本查询流程可用（每平台有验证记录）；
- 三驱动能力矩阵完成，未支持项明确标注；
- 冷启动、空闲内存、大结果集基准数据入库；
- 安全清单（凭据、日志、IPC、错误信息、路径）全部通过；
- 无 P0/P1 未解决缺陷；已知限制写入发布说明。

## 发布检查清单

每次发布前逐项确认，结果写入 PR 或发布说明：

1. `cargo fmt --all -- --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test` 通过；
2. 目标平台完成真实构建与启动验证（无法验证的平台明确标注）；
3. `docs/product/requirements.md` 的状态列与实现一致；
4. 支持矩阵（数据库 × 能力）更新，未支持项写明错误语义；
5. 安全复核：日志无 token/密码、端点文件 0600、IPC 仅本机、错误信息无敏感内容；
6. 升级/兼容：proto 无破坏性变更，或有主版本升级说明；
7. 打包产物与安装步骤在干净环境验证；
8. 发布说明包含：新增能力、行为变化、已知限制、升级注意事项。

## 支持矩阵（v0.1）

| 能力 | SQLite（v0.1） | PostgreSQL | MySQL |
|---|---|---|---|
| 连接 / 测试连接 | 已实现：本地文件、`read_only` 模式、`SELECT sqlite_version()` 作为版本探测 | 未实现 | 未实现 |
| 执行 / 分批结果 | 已实现：单语句、prepared statement 游标分批、服务端批次上限 5000 行 | 未实现 | 未实现 |
| 类型映射 | 已实现：NULL/INTEGER/REAL/TEXT/BLOB 按实际存储类映射；NUMERIC 与 DATE/DATETIME 保留原始类型名、不伪造 Decimal 与时间戳；非法 UTF-8 按字节返回 | 未实现 | 未实现 |
| 大字段截断 | 已实现：单格 64 KiB、文本按字符边界截断并置 `truncated`；延迟加载未实现 | 未实现 | 未实现 |
| 取消 | 已实现：`InterruptHandle` 中断、幂等、2 秒内生效 | 未实现 | 未实现 |
| 多语句 | 未实现：v0.1 单语句，第二条语句返回 `capability.unsupported` | 未实现 | 未实现 |
| 事务 | 未实现（M4） | 未实现 | 未实现 |
| 元数据 / 对象树 / 列信息 / DDL | 未实现（M4） | 未实现 | 未实现 |

> 该矩阵只允许填写「已实现并有测试」的能力。v0.1 的 SQLite 行验证方式：
> `cargo test -p sqarvo-driver-sqlite`（类型映射与截断）、
> `cargo test -p sqarvo-rpc-server --test grpc_sqlite_e2e`（UDS 端到端、批次上限、取消时限、
> 断连归零），两者均在 CI 的 `backend` 作业中显式执行。

## 兼容与弃用

- `0.x` 期间允许破坏性变更，但必须在发布说明中列出迁移方式；
- gRPC 字段编号一旦发布不得复用；删除字段使用 `reserved`；
- 端点文件格式变更必须提升 `protocol_version`，前端需能识别不兼容并提示升级；
- 配置格式变更需要迁移逻辑或明确的手动步骤。
