# 风险登记

概率/影响：高 / 中 / 低。触发信号用于尽早发现，而不是事后解释。
负责人为角色，不是具体个人。

| ID | 风险 | 概率 | 影响 | 缓解措施 | 触发信号 | 负责人 |
|---|---|---|---|---|---|---|

## 使用方式

- 每个里程碑评审时检查 R-01、R-04、R-05、R-14；
- 新增风险必须登记，不允许只在聊天或 Issue 中口头记录；
- 风险关闭需注明依据（测试、ADR、发布验证）。
