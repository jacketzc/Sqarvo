# 路线图

状态标记：`已完成` / `进行中` / `未开始`。未开始的能力不得在 UI 中表现为可用。

## Phase 0：骨架（当前）

| 事项 | 状态 |
|---|---|
| 仓库结构、文档骨架、ADR | 已完成 |
| Protobuf 契约（5 个域服务） | 已完成 |
| Rust workspace 与 crate 边界 | 已完成 |
| 本地 IPC（UDS + token）与端点文件 | 已完成 |
| Driver SPI 类型与能力模型 | 已完成 |
| 连接/会话管理、查询登记、元数据分页 | 已完成 |
| gRPC 冒烟测试（真实 UDS） | 已完成 |
| 三个平台的 UI 骨架 | 已完成（未接后端） |

## Phase 1：可用连接与浏览

| 事项 | 状态 |
|---|---|
| PostgreSQL 驱动（连接、取消、类型映射、分页游标） | 未开始 |
| 操作系统凭据存储（三平台） | 未开始 |
| 前端启动后端 + 读取端点文件 + token 认证 | 未开始 |
| 对象树（Catalog/Schema/表/列，按需加载） | 未开始 |
| SQL 编辑器与结果网格（虚拟化） | 未开始 |
| 事务：开始/提交/回滚与状态展示 | 未开始 |

## Phase 2：编辑与导出

| 事项 | 状态 |
|---|---|
| 表数据编辑、脏数据标记、安全提交 | 未开始 |
| 结果导出（CSV/JSON/SQL，流式写入） | 未开始 |
| 多语句与多结果集 | 未开始 |
| 查询历史与收藏 | 未开始 |
| SQLite 驱动（本地文件，便于无服务器测试） | 未开始 |

## Phase 3：高级能力

| 事项 | 状态 |
|---|---|
| Import/Export 向导 | 未开始 |
| Schema 对比与迁移脚本 | 未开始 |
| 备份/恢复 | 未开始 |
| Windows Named Pipe + ACL、macOS XPC 评估 | 未开始 |
| 大字段延迟加载与截断策略 | 未开始 |

## 质量门槛

- 每个驱动必须有集成测试（专用测试库 + 合成数据）；
- 每个性能优化必须先有基准数据；
- 每个发布版本更新支持矩阵与已知限制。
