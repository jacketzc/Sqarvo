# 产品需求

本文件定义功能范围与优先级，是路线图与里程碑的上游依据。

- 优先级：**P0** 首个可用版本必须；**P1** 后续版本；**P2** 已规划但未排期。
- 状态：**已实现**（代码与测试均存在）、**部分**（契约或部分逻辑已存在，尚不可用）、
  **未实现**。任何未实现能力不得在 UI 中表现为可用。
- 验收标准写在需求行内；具体任务拆解在 GitHub Issues，不在本文件重复维护。

## 2. 数据库对象与元数据

| ID | 需求 | 优先级 | 状态 | 验收要点 |
|---|---|---|---|---|
| REQ-META-001 | 对象树按需加载（Catalog / Schema / 表 / 视图 / 序列等） | P0 | 部分 | **两驱动已交付 Catalog → 表/视图/序列 → 列/索引/触发器 的逐层懒加载**（#82，PR #94 / `43373e7`）：SQLite 的 catalog 为 `main` / `temp` / `ATTACH`，MariaDB 的 database 即 catalog；跨库引用必须显式给出 catalog，子节点的 catalog 由服务端填满并可原样回传给 `GetColumns` / `GetPrimaryKey`；不存在的库/表 `metadata.object_not_found`、无权限 `metadata.permission_denied`、不存在的层级 `capability.unsupported`、种类不适用 `metadata.object_kind_unsupported`（都不返回空列表）；每层分页按（种类, 名字）排序，键含种类与父节点作用域。`cargo test -p sqarvo-driver-sqlite --test metadata_hierarchy` → 8 通过；`SQARVO_MARIADB_URL=… cargo test -p sqarvo-driver-mariadb --test integration` → 69 通过（含 `metadata_catalog_*` / `metadata_hierarchy_*` 等层级与跨库用例）。Linux 前端可折叠对象树（#86，PR #98 / `a6008c1`）与对象搜索（#84，见 REQ-META-004）已可用。**剩余缺口**：schema 层没有任何驱动实现——SQLite / MariaDB 本就没有独立 schema，PostgreSQL 驱动未实现，请求 schema 一律 `capability.unsupported`；MariaDB 受限账号下「库不存在」与「无权限」都只拿到 1044，只能报 `metadata.permission_denied` 并在文案里说明歧义 |
| REQ-META-002 | 列信息（原始类型、精度、可空、默认值） | P0 | 已实现 | `GetColumns` 返回原始类型名（SQLite 声明类型 / MariaDB `COLUMN_TYPE`，含长度与 `unsigned`）、可空性、MariaDB 的精度与标度、**默认值**（四态：未指定 / 明确无默认 / 默认 NULL / 未求值表达式，空串默认值不等于「无默认值」）、以及 MariaDB 的字符集与排序规则（`information_schema.COLUMNS`）。SQLite 没有列级字符集/排序规则概念，proto 用 `optional` 字段留空表示「不适用」，不用空串冒充。SQLite `columns_preserve_declared_type_and_nullability`、`columns_expose_default_value_and_only_what_sqlite_knows`（逐列断言 NoDefault/Null/Expression）；MariaDB 集成用例覆盖 `COLUMN_TYPE`、默认值与 `CHARACTER_SET_NAME`/`COLLATION_NAME`（#45、#59，PR #54 / `100f43d`、PR #64 / `c78d6b6`）。**前端**：Linux 数据页点表头第二行（原始类型）把右侧信息面板切到该列页，逐列展示默认值四态 / 字符集 / 排序规则，缺省字段显示「不适用」（#87，PR #92 / `bcb12c4`；v0.2.3.2 起列信息从页内浮层迁入信息面板，QA 的 `--qa-column-info` 走同一条点类型行路径）。**剩余**：`ENUM` / `SET` / `GEOMETRY` / `BIT` 以 `ColumnType::Unsupported { type_name }` 保留原文；SQLite 的列排序规则仍恒为 `None`（`pragma_table_info` 不提供，且本版不解析 DDL） |
| REQ-META-003 | 查看 DDL | P1 | 已实现 | `GetDdl` 返回 `ddl / exact / source / source_detail / generator_version`；两驱动都只交付数据库原文（`exact=true`、`source=DDL_SOURCE_DATABASE`），**没有客户端拼装路径**；`exact=false` 时 rpc-server 还要求来源与生成器版本（`is_consistent()`），说不清来源就以 `internal.error` 拒绝。SQLite 覆盖表/视图/索引/触发器（`sqlite_master.sql` 原文；`sqlite_autoindex_*` 无原文 → `capability.unsupported`）；MariaDB 覆盖表/视图/序列（`SHOW CREATE` **第 2 列**原文并校验 `CREATE` 前缀；索引/触发器无独立 DDL → `metadata.object_kind_unsupported`）。`GetDdl` 纳入会话执行锁（`grpc_session_locks_e2e` 8 通过，含 `ddl_holds_lock_against_apply` / `ddl_waits_for_apply`）。DDL 不截断，超过 gRPC 消息上限（tonic 默认 4 MiB）时请求失败而非返回半截文本。验证：SQLite `--test metadata` 13 通过（其中 5 个 `ddl_*`）、MariaDB 集成 69 通过（4 个 `metadata_ddl_*`）、`grpc_metadata_e2e` 1 通过（断言 `exact=true` 与来源）；Linux DDL 面板（#86）只显示正文，`exact=false` 时正文上方保留拼装警示（v0.2.3.3 移除了来源徽标、来源说明行与「复制」按钮：复制走选中 + `Ctrl+C`）。**剩余**：MariaDB 索引/触发器 DDL 需要 `ObjectRef` 携带所属表（契约增量，待定）；没有业务层体积上限错误码（超限是传输层失败） |
| REQ-META-004 | 对象搜索与过滤 | P1 | 已实现 | `ListNodesRequest.filter`（`contains` / `exact` 同一 oneof + `kinds`）**下推到数据库**（#84，PR #96 / `8e7c661`）：SQLite `LIKE … ESCAPE '\'`、MariaDB `LIKE CONCAT('%', ?, '%')`，`%` / `_` / `\` 按字面量转义；过滤结果 token 为 `v2:<offset>:<集合指纹>:<过滤标签>`，换关键词 / 换匹配方式 / 增删 kinds → 旧 token `config.invalid`（不回退第一页）。SQLite `--test metadata_filter` 13 通过（+1 ignored 规模基准）、MariaDB `--test metadata_filter` 9 通过（+1 ignored）。**大小写差异（文档写明，不统一）**：`contains`（`LIKE`）在 SQLite 只折叠 ASCII、在 MariaDB 走 `utf8mb3_general_ci`（连重音一起折叠）；`exact`（`=`）两驱动都是二进制比较、区分大小写。**性能**：SQLite 10 万对象命中 3 个 9.3 ms（release，`#[ignore]` 基准，#84 记录）；MariaDB 只测 1 万对象 7.2 ms（10 万未实测，见发布计划「未验证项」）。**剩余**：Linux 搜索只覆盖当前库根层、只展示首页 500 条；`NO_BACKSLASH_ESCAPES` 下 MariaDB 默认转义符失效，本版不处理 |
| REQ-META-005 | 表/视图数据预览（分页、排序、筛选、总数） | P1 | 已实现 | **已交付（v0.2.2）**：`TableDataService.BrowseTable` 固定主键升序 + 不透明 cursor，每页上限 500，游标非法 → `table_data.cursor_invalid` 且不回退第一页；无主键表/视图返回 `read_only=true`（原因 `NoPrimaryKey`、排序 `Unstable`）。SQLite `cargo test -p sqarvo-driver-sqlite --test table_data`（9 用例）、MariaDB 集成用例、gRPC `cargo test -p sqarvo-rpc-server --test grpc_table_data_e2e`（#46，PR #55 / `8775dda`）；Linux 数据页按主键翻页并显示原始类型列头。**v0.2.3 改写分页口径（ADR 0022）**：请求增 `offset` / `sort` / `filter` / `include_total`，响应增 `total_rows` / `total_kind`（UNKNOWN / ESTIMATE / EXACT 三态必须显式），`offset` 与 `page_token` 互斥；排序与筛选由驱动下推，列名走白名单、值全部参数化绑定；offset 分页跨页不保证稳定（重复/漏行是固有属性，界面提示不修复），大 offset 跳转不提供。**v0.2.3 驱动侧已落地（#110 / #111）**：SQLite 与 MariaDB 均把 `ORDER BY`（多列、方向）/ `WHERE`（9 算子、仅 AND）/ `LIMIT ? ## 10. 非功能约束（适用于全部需求）

- 数据库密码不得出现在配置、日志、错误信息、崩溃报告与测试快照中；
- 不支持的能力必须返回明确错误（`UNIMPLEMENTED` / `capability.unsupported`），

- 所有长任务必须可取消，取消必须幂等；
