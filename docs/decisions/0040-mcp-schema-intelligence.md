# ADR 0040 · MCP 结构感知的元数据和查询计划

状态为已接受，维护者授权「确认 #6」。关联 REQ-MCP-015、#251、ADR 0032、0033、0039。

## 背景

MCP 的首屏目录和单表 Resource 可发现对象，但无法按需分页并附带约束、索引和外键。
Driver SPI 已能读取列、主键和原生 DDL。两个驱动的旧目录路径先收集对象再切页，
元数据指令也没有供 QueryRegistry 使用的取消标识。

## 备选与决定

- 要求 Agent 分别查询系统目录会把方言差异、权限过滤和估算口径转给客户端。
  将这些事实收敛到 Driver SPI，MCP 只投影存量或新增的驱动元数据。
- Resource URI 可以扩展查询参数。采用一个 `get_database_schema` 工具以复用
  参数 Schema、工具选择策略、双传输路由和审计。旧目录和单表 Resource 保留原契约。
- 新目录页将筛选、续页和限额下推数据库。详情页只读取有限对象和所选部分。
  元数据 worker 按 Query ID 处理取消，在请求截止后保留原会话执行锁与并发许可至清理完成。
- 查询计划方言由驱动声明。MCP 验证原 SQL 后生成固定前缀并复用 `run_sql`。
  MariaDB 沿用普通 EXPLAIN，SQLite 使用本地方言的同一只读 AST 遍历，
  SQLite 驱动校验原生语句边界时不会编译尾部 SQL。这一决定替代 ADR 0032 的 MCP 方言名单例外。
- 原生定义表示数据库输出。模式裁剪与预算丢弃显式记录。统计表达现有空值和估算，
  不主动采样、计数或更新统计。既有 Protobuf、结果集列元数据和写入状态机继续独立演进。

## 代价与重新评估条件

外部 DDL 可能造成页间漂移或详情变化。SQLite 的复杂声明可能超出解析覆盖，
此时保留 PRAGMA 事实并标记缺项。SQLite 无可靠单表字节数。MariaDB 的目录可见性
取决于账户权限，引擎统计可能陈旧。需要跨页快照、详细目录读取成为可测瓶颈，
或有新驱动接入时，重新评估目录批读、游标及能力覆盖。
