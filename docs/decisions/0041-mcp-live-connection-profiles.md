# ADR 0041 MCP 连接标识与档案热更新

- 状态：已接受（2026-11-24）
- 更新 [ADR 0035](0035-shared-connection-profiles.md) 的启动时会话槽位规则，适用于 stdio 和 [Streamable HTTP](0036-local-mcp-http.md)。

## 背景

共享档案在每个请求中读取，但会话槽位原来固定在进程启动时的档案版本。保存新档案或修改名称后，
连接列表能显示新值，实际调用需要重启。旧列表的单个 `alias` 字段还无法同时提供稳定标识和可读名称。

## 决策

- 连接发现同时返回档案 UUID `connection_id`、展示用 `display_name` 和旧 `alias`。
  工具与资源继续接受现有 `connection_alias` 参数，UUID 可直接用作参数值。
- 复用请求时读取的共享档案快照同步读取会话槽位。每个 UUID 的当前 revision 按需建连。
  移除的槽位停止交付新租约，空闲连接关闭，已取得租约的读取完成后关闭旧连接。
- 请求一旦解析目标，使用同一 UUID 和 revision 完成建连检查及读取重试。
  全局授权、MariaDB 写入资格与显式事务的版本校验继续生效。

## 取舍与重新评估条件

继续使用启动快照会留下进程重启问题。引入文件监听需要处理替换文件、多进程事件及平台差异，
而请求已读取最新档案。复用档案 revision 也会在仅改名时使读取会话重连。
若实际使用中频繁更名产生明显连接开销，再评估区分显示字段和连接参数。
