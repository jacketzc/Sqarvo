# v0.1 发布说明

- 状态：**已完成**（2026-11-04，Linux 验证）
- 覆盖里程碑：M0 骨架、M1 契约冻结、M2 首个驱动切片
- 范围：**仅后端 + SQLite**。本版本没有可用的图形前端。

## 一句话概括

v0.1 交付「本地 IPC + gRPC 契约 + Driver SPI v0.2 + SQLite 驱动垂直切片」：
一个真实的 gRPC 客户端可以通过 Unix 域套接字连到后端，在 SQLite 上执行 SQL、
分批拉取结果、取消查询并正常关闭。

**它不是可用的数据库客户端**：三端前端仍是骨架，PostgreSQL / MySQL 未实现，
事务与元数据 RPC 仍返回 `UNIMPLEMENTED`，凭据存储尚未实现。

## 新增能力

| 能力 | 说明 | 验证方式 |
|---|---|---|
| Protobuf / gRPC 契约 | 5 个域服务；`System` / `Connection` / `Query` 已真正接线，`Metadata` / `Transaction` 明确返回 `UNIMPLEMENTED` | `cargo test -p sqarvo-rpc-server` |
| 本地 IPC 与访问控制 | Linux/macOS 使用 Unix 域套接字（目录 0700、socket 0600）；每进程随机 256 位 token，写入 0600 端点文件；拒绝非回环 TCP | `grpc_smoke.rs`、真实二进制运行记录 |
| Driver SPI v0.2 | `ExecutionStart` / `StatementSummary` / 按 `statement_index` 的游标 / 事务与元数据接口 / `Cell.truncated`（ADR 0005–0009） | `cargo test -p sqarvo-driver-api` |
| SQLite 驱动 | 连接（本地文件、`read_only`）、单语句执行、语句摘要、prepared statement 游标分批、`InterruptHandle` 取消、关闭清理 | `cargo test -p sqarvo-driver-sqlite` |
| 类型映射 | NULL / INTEGER / REAL / TEXT / BLOB 按实际存储类映射；NUMERIC 与 DATE/DATETIME 保留原始类型名、不伪造 Decimal 与时间戳；非法 UTF-8 按字节返回 | `tests/type_mapping.rs`（12 用例） |
| 大字段截断 | 单格 64 KiB 上限，文本按 UTF-8 字符边界截断并置 `truncated` | `tests/type_mapping.rs` |
| 取消 | gRPC `Cancel` 幂等；驱动中断在 2 秒内生效 | `grpc_sqlite_e2e::cancel_interrupts_running_fetch_within_deadline` |
| 查询生命周期 | 会话级串行化、并发查询上限 8、批次默认 200 / 上限 5000、断连回收查询登记 | `grpc_sqlite_e2e`（批次上限、断连归零） |

完整的能力矩阵见 [release-plan.md](../planning/release-plan.md) 的「支持矩阵」一节；

## 已知限制

以下能力**不可用**，且不会伪造成功（返回 `UNIMPLEMENTED`、`capability.unsupported`
或明确的领域错误）：

- **无前端**：Windows / Linux / macOS 三端 UI 仅为骨架，未连接后端；
- **无网络数据库驱动**：PostgreSQL / MySQL 的连接请求返回 `driver.not_found`；
- **无事务 RPC**：`TransactionService` 返回 `UNIMPLEMENTED`，SQLite 驱动能力声明
  `transactions=false`（M4 接线）；
- **无元数据 RPC**：对象树、列信息、DDL 返回 `UNIMPLEMENTED`（M4）；
- **无凭据存储**：只有接口与「不可用」实现，缺失时明确报错，不回退明文；
- **不支持多语句**：第二条语句返回 `capability.unsupported`（ADR 0006）；
- **取消的契约边界**：`query_id` 在首批返回后才产生，因此「已开始执行但尚未返回首批」
  的查询无法用 `Cancel` 打断，只能依赖 `timeout_millis`（v0.2 候选改进）；
- **大字段只能标记截断**：不提供延迟加载或完整值回取；
- **无结果集内存上限与背压**（`REQ-RESULT-005` 未实现）；
- **平台验证范围**：仅在 Linux 上构建与测试；Windows Named Pipe + ACL 未实现
  （回退为回环 TCP + token），Windows / macOS 未做构建验证；
- **无性能基准**：启动时长、空闲内存、大结果集基准属于 M6（`REQ-PERF-001`）。

## 兼容性与升级

- gRPC 契约版本 `protocol_version = v1`，端点文件随 token 与 socket 路径变化；
- M1 之后 proto 仅做增量修改，未复用字段号、未删除已发布字段；
- `0.x` 期间允许破坏性变更；若后续版本调整契约或端点文件格式，会在对应发布说明中
  给出迁移步骤，并通过 `protocol_version` 让前端识别不兼容；
- 这是首个发布版本，无升级动作。

## 安全说明

- 数据库密码、密钥等凭据在 v0.1 尚无存储路径（SQLite 不需要凭据）；
- token 只写入 0600 端点文件，日志中不输出；连接只允许本机，非回环地址被拒绝；
- 用户可见错误只包含固定文案与稳定错误码（`sqarvo-error-code`），底层细节仅作为
  错误 `source` 保留，不拼接进 gRPC 状态消息。
